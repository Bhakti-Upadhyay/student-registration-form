# Student Course Registration Web Application

A full-stack web application that allows students to register, log in, and view available courses through an online portal.

## Technologies Used

HTML5, CSS3, JavaScript, Node.js, Express.js, MongoDB, and Mongoose.

## Features

* Student registration and login
* View available courses
* Interactive frontend using JavaScript and DOM
* Backend API with Node.js and Express
* Data storage and management using MongoDB
